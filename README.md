# SQL_analyse

## 📊 Опис проєкту

Цей репозиторій містить SQL-запити та аналітичні сценарії, створені на основі навчального датасету, отриманого з YouTube-каналу [Data with Baraa](https://www.youtube.com/@DataWithBaraa). Мета проєкту — практичне опрацювання ключових тем SQL-аналітики: сегментація клієнтів, часовий аналіз, порівняння продуктивності та робота з агрегованими показниками.

## 📌 Основні компоненти

### 🔹 `/database/`
Містить CSV-файли з трьома таблицями:
- **`gold.dim_customers.csv`** – інформація про клієнтів
- **`gold.dim_products.csv`** – довідник продуктів
- **`gold.fact_sales.csv`** – фактичні дані про продажі

### 🔹 `/queries/`
SQL-запити, що охоплюють різні бізнес-завдання:
- **Segmentation.sql** – розподіл клієнтів за групами
- **Changes over time.sql** – аналіз змін у часі
- **Performance.sql** – оцінка ефективності продажів
- та інші
